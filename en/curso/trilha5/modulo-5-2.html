🌐 Classic SEO and AEO in the same audit

There are two visibility games today. The SEO targets Google: ranking on the results page. The AEO (Answer Engine Optimization) targets answer engines—ChatGPT, Perplexity, Gemini, Claude—so it can be cited in the AI response. They’re different audiences, signals, and checks. This skill covers both in one pass.

🔵 Traditional SEO

Show up and rank on Google.

  • •Title, meta description, H1/H2 hierarchy
  • •Core Web Vitals, HTTPS, sitemap
  • •Internal links, alt text, E-E-A-T

🟦 AEO (AI search)

Be cited in the AI’s response.

  • •AI crawlers allowed in robots.txt
  • •llms.txt and direct answer blocks
  • •Schema, entity authority, SSR

🧩 Why this is a differentiator

Market SEO tools don’t check whether AI bots can access your site or generate llms.txt. Guides on “how to show up in ChatGPT” rarely measure Core Web Vitals or schema. Whoever delivers both in the same report, without switching tools, offers something the client can't find anywhere else.

2

🤖 robots.txt and the invisible block

The most costly failure in AEO is silent: a rule in the robots.txt that blocks an AI crawler. If the GPTBot is prohibited, ChatGPT never indexes your site—and no one notices because Google traffic stays the same. The skill checks exactly that and marks it as a high priority.

AI crawler access check bash 
curl -s "https://DOMINIO/robots.txt" \
  | grep -iE "GPTBot|ClaudeBot|PerplexityBot|GoogleOther|Bytespider|CCBot"

# Se qualquer crawler critico aparecer em "Disallow: /"
# => sinalizar como FIX DE PRIORIDADE ALTA

User-agent: GPTBot
User-agent: ClaudeBot
User-agent: PerplexityBot
User-agent: GoogleOther
Allow: /

✗ The rule that makes AI erase you

User-agent: GPTBot
Disallow: /

# GPTBot nunca le seu site.
# Voce some das respostas do ChatGPT.

⚠️ Attention

Many CMS templates and “privacy” plugins add anti-AI rules by default, thinking they protect the content. The site owner almost never knows. Always start the audit with robots.txt — it’s the highest-impact finding and the easiest to fix.

3

📄 llms.txt: the map for AI

O llms.txt is a machine-readable file at the root of the site that tells AI where to find your authoritative content—docs, guides, glossary, research. It’s the highest-impact AEO action most websites still haven’t taken. The skill generates the llms.txt e o llms-full.txt ready for deployment.

llms.txt (skeleton generated by the skill) site root 
# {nome_da_marca}

> {descricao_da_marca em uma frase}

## Core Documentation
- [Como funciona](/docs): visao geral do produto

## How-To Guides
- [Primeiros passos](/guias/inicio): tutorial passo a passo

## Definitions & Glossary
- [Glossario](/glossario): termos-chave do setor

## About & Authority
- [Sobre](/sobre): credenciais, equipe, time
- [Imprensa](/imprensa): mencoes e reconhecimento

## Contact
- [Contato](/contato): fale com a equipe

📊 llms.txt vs llms-full.txt

  • llms.txt — the index: links with a one-line description for AI to navigate.
  • llms-full.txt — the content: the full text of the key pages, so AI can cite it without having to search.

🏷️ Schema markup and response blocks

For the AI extract and cite your content confidently, it needs structure. Two techniques dominate: the schema markup (JSON-LD that describes the page to machines) and the answer block method (question in the H2, direct answer right below).

FAQPage schema (JSON-LD) <script type="application/ld+json"> 
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [{
    "@type": "Question",
    "name": "O que e AEO?",
    "acceptedAnswer": {
      "@type": "Answer",
      "text": "AEO (Answer Engine Optimization) e otimizar
               conteudo para ser citado por IAs como ChatGPT
               e Perplexity, alem do ranqueamento no Google."
    }
  }]
}

📐 The response block method

[direct answer in 1–2 sentences, right after the title]

🔬 The Live Audit Flow

When you type audit https://site.com, the skill runs a fixed sequence: finds the core files, checks bot access, detects the schema, and generates the prioritized report. Understanding the workflow is what lets you trust the result — and extend it.

1

Search core files

robots.txt, sitemap.xml, the page HTML (title, meta, H1), and the status of the llms.txt. All via curl/web_fetch.

2

Audit AI bot access

Look for GPTBot, ClaudeBot, PerplexityBot in robots.txt. Any critical block becomes a high priority.

3

Audit schema

Extract the blocks application/ld+json of the page and identify which types exist (or whether there are none).

4

Generate the report

Write seo-audit-DOMINIO.md with an executive summary, SEO and AI findings, schema and llms.txt status, and a plan divided into quick wins / medium term / long term.

⚡ Practical tip: competitors running in parallel

For a competitive analysis, trigger parallel subagents — one per competitor. Each audits a domain (HTML, schema, llms.txt, robots), and the main agent combines everything into a comparison table. Same skill, multiplied scope.

🛠️ Packaging your auditor

The actual skill is a clear example of progressive disclosure: the SKILL.md stays lean, with a decision tree and a concise playbook, and delegates the details to the references/. The scripts do the heavy lifting.

skill structure seo-aeo-optimization/ 
seo-aeo-optimization/
├── SKILL.md                    # playbook + arvore de decisao (enxuto)
├── scripts/
│   ├── audit.sh                # auditor de site ao vivo
│   └── generate_llms_txt.py    # gerador interativo de llms.txt
└── references/
    ├── traditional-seo.md      # checklists tecnicos, Core Web Vitals
    ├── ai-seo-aeo.md           # playbook AEO, taticas por plataforma
    └── schema-markup.md        # biblioteca JSON-LD copia-e-cola

🌳 The decision tree inside SKILL.md

request received
├─ "audit my site" → live audit flow
├─ "create schema markup" → read schema-markup.md → JSON-LD
├─ "write llms.txt" → read ai-seo-aeo.md → generate file
├─ "analyze competitors" → parallel subagents
└─ general question → answer using the skill's knowledge

📊 Why SKILL.md stays lean

The body of SKILL.md only needs enough to make a decision which path to follow and trigger the right script. The deep knowledge — 15 schema types, all platform-specific tactics — lives in the references/, loaded on demand. This keeps the context light and the skill fast.

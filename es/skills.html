🛠️ Cómo instalar una skill en Claude Code

Una Agent Skill es solo una carpeta con un SKILL.md dentro. Claude descubre la skill por description del frontmatter y la activa automáticamente cuando tu solicitud coincide con los desencadenantes descritos.

1

Crea la carpeta de la skill

Cada skill vive en ~/.claude/skills/<nome>/, con un SKILL.md dentro. El nombre de la carpeta debe coincidir con el name del frontmatter.

2

Coloca el archivo en su lugar

Descarga el SKILL.md (o descomprime el .skill/.zip) y muévelo a esta carpeta. Archivos adicionales — references/, scripts/, assets/ — quedan al lado y se cargan bajo demanda (divulgación progresiva).

3

Reinicia Claude Code

Cierra y vuelve a abrir la sesión (o ejecuta /skills) para que Claude vuelva a indexar las skills. A partir de ahí, activa la skill automáticamente cuando tu solicitud coincide con la description.

terminal

# 1. criar a pasta da skill (escopo do usuário, vale em todo projeto)
mkdir -p ~/.claude/skills/travel-itinerary

# 2. mover os arquivos baixados para dentro
mv ~/Downloads/SKILL.md            ~/.claude/skills/travel-itinerary/
mv ~/Downloads/README.md           ~/.claude/skills/travel-itinerary/
mv ~/Downloads/DESIGN-REFERENCE.md ~/.claude/skills/travel-itinerary/

# para um pacote .skill ou .zip, descompacte primeiro:
unzip ~/Downloads/n8n-workflow-reviewer.skill -d ~/.claude/skills/

# 3. reiniciar o Claude Code — pronto, a skill dispara pela description

💡 Consejo: alcance del proyecto vs. usuario

Para que una skill se aplique solo a un repositorio, usa .claude/skills/<nome>/ dentro de la raíz del proyecto, en vez de ~/.claude/skills/. Las skills de proyecto van al control de versiones y acompañan al repo; las skills de usuario funcionan en cualquier carpeta de tu máquina.
